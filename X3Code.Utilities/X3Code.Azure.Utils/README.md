# X3Code.Azure.Utils

Helfer rund um Microsoft-Azure-Dienste.

```shell
dotnet add package X3Code.Azure.Utils
```

## Inhalt

`IAzureStorage`, `StorageBase` und `AzureBlobStorage` — Auflisten, Prüfen, Herunterladen,
Hochladen und Löschen von Blobs über das Azure-Storage-SDK.

## Ziel-Framework

`net10.0`
